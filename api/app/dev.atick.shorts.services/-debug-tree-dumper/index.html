DebugTreeDumper

object DebugTreeDumper

TEMPORARY DEBUG HELPER — remove once Reels detection is finalised.

Dumps the accessibility node tree (view ids, content descriptions, text, class, selected state) of a screen to Downloads/shorts-blocker-dump.txt so the exact identifiers of Instagram's Reels player UI can be inspected without adb/a PC. Dumps are appended, each prefixed with a header, so several screens can be captured in one session.
