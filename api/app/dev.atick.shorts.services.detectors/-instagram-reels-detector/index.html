InstagramReelsDetector

class InstagramReelsDetector : ShortFormContentDetector

Detector for Instagram Reels short-form content.

This detector identifies when a user is actively watching Instagram Reels and, crucially, avoids false positives on Direct messages, Stories and Settings — screens the previous implementation wrongly treated as Reels.

Detection Strategy:

  1. Early exit for non-Reels screens: if a Stories viewer (reel_viewer) or a Direct/inbox screen (direct_, thread_) node is seen, immediately return false.

  2. Reels tab detection: if the clips_tab node exists and is selected, it's Reels.

  3. Fullscreen Reels detection: a positive clips_viewer/clips_video signal combined with the absence of the bottom navigation (feed_tab) indicates Reels opened from the feed, Explore or a profile.

The key fix over the old logic: Reels is only reported on a positive Reels signal. The mere absence of feed_tab is no longer treated as Reels, because Direct, Stories and Settings also lack it.

Implementation Details:

  • Performs a breadth-first scan of up to 300 nodes. The previous 10-node scan only reached the bottom navigation, which is why "no feed_tab" became a (wrong) proxy for Reels.

  • Instagram reuses clips_viewer widely, so detection relies on combined signals rather than any single node.

Known Limitations:

  • Detection patterns may break after major Instagram redesigns.

  • The 300-node cap may miss Reels signals in unusually deep layouts.

Compatibility:

  • Tested with Instagram app versions 300.x - 320.x

  • May require updates for major Instagram redesigns
